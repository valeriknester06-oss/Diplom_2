# Diplom_2

Автоматизация тестирования API сервиса Stellar Burgers.

Проект представляет собой фреймворк для автоматизированного тестирования REST API функциональности космической бургерной. Реализован полный цикл работы с тестовыми данными: от генерации пользователей до очистки данных после выполнения тестов.

## Используемые технологии

* Java 11
* Maven
* JUnit 4
* REST Assured
* Allure Report
* Lombok
* Jackson
* Java Faker

## Архитектура проекта

Проект реализован с использованием нескольких подходов и паттернов:

### POJO (Plain Old Java Object)

Созданы модели данных:

* User
* Order

Для удобной сериализации и десериализации JSON.

### Service Object / Client

Логика взаимодействия с API вынесена в отдельные client-классы:

* UserClient
* OrderClient

### Data Generator

Для генерации тестовых данных используется Java Faker.

### DRY (Don't Repeat Yourself)

Общие настройки вынесены в базовые классы и Request Specification.

## Реализованные проверки

### Регистрация пользователей

Проверены сценарии:

* создание уникального пользователя;
* создание существующего пользователя;
* создание пользователя без обязательных полей.

### Авторизация

Проверены сценарии:

* успешный логин;
* вход с неверными данными.

### Работа с заказами

Проверены:

* создание заказа с авторизацией;
* создание заказа без авторизации;
* создание заказа с ингредиентами;
* создание заказа без ингредиентов;
* создание заказа с неверным хешем ингредиентов.

## Управление тестовыми данными

Реализована автоматическая очистка данных после выполнения тестов:

* удаление созданных пользователей;
* использование access token для cleanup.

Это обеспечивает независимость тестов и стабильность повторных запусков.

## Отчетность

Для формирования отчетов используется Allure Report.

Использованы аннотации:

* @Step
* @DisplayName
